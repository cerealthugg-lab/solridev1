1. WHAT IS SOLRIDE
--------------------------------------------------------------------------------
SOLRIDE is a skateboarding social + move-to-earn (M2E) mobile web app.
Target platform: iOS App Store (via Capacitor). Also runs in browser.
Status: In active development, being polished for Apple App Store submission.

Core features:
- Spots Map: skaters pin real-world skate spots, upload photos
- Trick Feed: upload video clips of tricks at spots; social feed (like/tip)
- DFQ Points: in-app utility points earned by riding/uploading (NOT crypto/cash)
- Wallet Page: DFQ balance, tip tricks with DFQ
- Global Chat: live public chat room (10s cooldown, profanity filter, bans)
- Direct Messages: 1-on-1 DMs between skaters
- Profile: own profile (MyProfile), other skater profiles (SkaterProfile)
- Ride Page: start/stop a skate session to earn DFQ

11. BACKEND — TRICKS ENDPOINTS PATTERN

1. Fetch tricks from supabase
2. Attach spot names (_attach_spot_names)
3. Attach comment counts (_attach_comment_counts)
4. Attach user_photo_url (by joining users table on username)
5. Filter blocked users (_visible + _blocked_set)

user_photo_url attach pattern (Python):
  unames = list({t['user_id'] for t in tricks if t.get('user_id')})
  user_map = {}
  if unames:
      urs = supabase.table('users').select('username, photo_url').in_('username', unames).execute()
      user_map = {u['username']: u.get('photo_url') for u in (urs.data or [])}
  for t in tricks:
      t['user_photo_url'] = user_map.get(t.get('user_id'))
